HOTFIX JALUR PYTHON WINDOWS

1. Ekstrak dua file ini ke root proyek, contoh:
   D:\Coding\Py\merchants-promo\
   Izinkan Jalankan_Promo.bat dan Install_Dependency.bat ditimpa.

2. Sebelum menjalankan launcher, cek Python langsung di CMD:
   "D:\Python312\python.exe" --version
   "D:\Python312\python.exe" -c "import sys; print(sys.executable); print(sys.version)"

3. Jalankan tes offline dengan perintah PERSIS ini (tanpa backslash akhir):
   Jalankan_Promo.bat --test-only

Launcher sekarang menguji eksekusi Python nyata dari D:\Python312 terlebih dahulu. Jika jalur tersebut tidak valid, baru ia mencoba lokasi instalasi umum, py -3, lalu python. Ia tidak lagi mempercayai `where py` saja.

Jika tes path langsung gagal, folder Python mungkin hanya dipindah secara manual dan instalasinya tidak dapat berjalan dari lokasi baru. Dalam kasus itu, gunakan Python Installer untuk Repair atau reinstall ke D:\Python312, bukan mengandalkan launcher.
