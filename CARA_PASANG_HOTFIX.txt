HOTFIX PENCARIAN HARGA GRATIS

1. Ekstrak isi ZIP ini langsung ke folder D:\Coding\Py\merchants-promo.
2. Izinkan Replace untuk file yang diminta. ZIP ini tidak berisi database, hasil katalog, file .bat, atau output pengguna sehingga tidak menimpa data hasil run.
3. Tutup Excel terlebih dahulu.
4. Jalankan: python -m pytest -q engine
5. Jalankan: python engine\promo_free_price_finder.py --limit 5 --force
6. Jalankan: python engine\enrich_existing_promo_catalog_multisource.py
7. Buka hasil\Katalog_Promo_Final.xlsx dan cek sheet Kandidat Harga.

Kandidat harga belum terverifikasi tidak akan dipakai untuk median harga pasar/diskon resmi. Sheet Peluang Harga dapat tetap kosong bila belum ada dua domain yang lolos verifikasi.
